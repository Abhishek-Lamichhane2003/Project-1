Cauchy Population

A stress test for the assumptions of the Central Limit Theorem

Author

Abhishek Lamichhane — Student ID: 019102551

Code 
source("R/helpers.R")
set.seed(STUDENT_SEED)

location <- 0
scale <- 1
generator <- function(sample_size) {
  rcauchy(sample_size, location = location, scale = scale)
}

1 Why this case is different

The standard Cauchy distribution has extremely heavy tails. Its ordinary mean and variance do not exist, so there is no finite theoretical standard deviation to insert into sigma / sqrt(n). This means the usual finite-variance CLT argument is not applicable.

This is not a technical problem with the simulation. It is the main reason the Cauchy population is included.

3 Simulation

I investigated sample sizes n = 2, 5, 10, 20, 30, 50, 100, and 200. I used the same range as the other distributions so that the comparisons were fair. The smaller values show the immediate effect of the heavy tails, while the larger values test whether increasing n fixes the problem.

5 Approximate normal decision

The Cauchy population did not behave like the other populations. Extreme values continued to affect the sample means even when n became large. Since the Cauchy distribution has no finite ordinary mean or variance, the usual CLT standard-error formula does not apply. Therefore, I did not choose a sample size for this distribution. My final answer is: there is no reasonable value of n under the ordinary CLT conditions. The histograms and Q-Q plots kept showing heavy-tail behavior, and the simulated mean, standard deviation, skewness, and kurtosis were unstable. Because there is no finite theoretical standard error to compare with, the usual numerical check cannot be used here.

6 What surprised me

I was surprised that increasing the sample size to 200 did not make the sample-mean distribution behave like the other populations. A few extreme values could still have a large effect, which is exactly why the Cauchy case is an important exception to the usual CLT discussion.
